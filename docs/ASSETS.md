# Assets

Everything below is original work made for this project, defined in code or data. No third-party art,
fonts, sounds or game sprites are used.

| Asset | Where | Source | License |
|---|---|---|---|
| Stamps (heart, star, smiley, flower, cat, sword, mushroom, rocket, ghost, tree) | `core-model/.../Stamps.kt` | Hand-drawn as character maps for this app | Same as the project |
| Coloring pages (house, fish, dinosaur, robot, flower) | `core-model/.../ColoringPages.kt` | Built from lines, rectangles and ellipses in code | Same as the project |
| "Copy the picture" challenges | `core-model/.../Challenges.kt` | Reuse the stamps above | Same as the project |
| Palettes (Bright, Rainbow, Pastel, Forest, Ocean, Retro 8-bit) | `core-model/.../Palettes.kt` | Original color picks. "Retro 8-bit" is my own selection, not a console palette | Same as the project |
| UI icons (pencil, bucket, mirror, undo, …) | `ui/.../theme/PixelIcons.kt` | Hand-drawn 12×12 pixel art | Same as the project |
| Sounds (pop, splash, whoosh, click, wipe, ta-da) | `ui/.../platform/SoundSynth.kt` | Generated at runtime from sine waves and filtered noise | Same as the project |
| App icon (Android adaptive icon, desktop PNG/ICO/ICNS) | `androidApp/src/main/res`, `desktopApp/icons` | Original pixel face, generated by `tools/make_icon.py` | Same as the project |
| Fonts | — | The platform default system font. No font files are bundled | — |

Stamp, template and palette names are only labels. None of them copy or imitate copyrighted
characters.
